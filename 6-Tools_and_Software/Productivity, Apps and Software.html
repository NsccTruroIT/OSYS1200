Tools, Software, and Applications

In this module, we move beyond OS installation and security baselines to examine how Windows 11 organizes user data, stores system configuration in the Registry, and packages, installs, and removes applications at scale.

Module Objectives: By the end of this unit and Lab 6, you will be able to configure File Explorer and Search Indexing for administrative visibility, manage OneDrive sharing permissions securely, inspect and modify the Windows Registry safely, and compare/deploy .exe, .msi, AppX/MSIX, and winget software packages.

1. Windows Productivity Tools

File Explorer & Windows Search

  • Show File Extensions & Hidden Items: By default, Windows hides known file extensions (e.g., showing invoice.pdf.exe as invoice.pdf). Enabling View → Show → File name extensions and Hidden items is a mandatory first step for troubleshooting and security awareness.
  • Tabs & Navigation: Windows 11 File Explorer supports multi-tab browsing (Ctrl+T) and quick path navigation via the address bar (including environment variables like %USERPROFILE%\Downloads).
  • Libraries: A virtual collection that aggregates multiple physical folders (e.g., your local Documents and C:\Users\Public\Documents) into one unified view, with a configurable default save location.
  • Windows Search Indexing: Windows Search relies on a background index database rather than scanning the entire disk on every query. Folders outside default user profiles (e.g., C:\NewData) do not appear in filtered Documents search results until added in Settings → Privacy & security → Searching Windows → Customize search locations.

OneDrive (Personal vs. Work/School)

  • Personal vs. M365 Business/Education: Personal OneDrive ties to a consumer Microsoft Account, whereas NSCC's M365 OneDrive for Business is governed by Entra ID / SharePoint policies (supporting organization-only links, audit logs, and link expiration dates).
  • Files On-Demand: Cloud-only placeholders save local disk space (especially important on VMs), downloading files only when opened unless pinned as Always keep on this device.
  • Sharing & Access Control: Always follow least privilege when sharing—prefer Specific people or Read-only (Can view) links over open Anyone with the link can edit, set expiration dates when available, and use Manage access to audit or revoke active links.

Printers, Drivers & Browsers

  • Printing Architecture: Print jobs queue through the Print Spooler service (spoolsv.exe) before reaching local USB or TCP/IP network printers. Administrators stage and inspect printer .inf packages in the Windows Driver Store using pnputil.
  • Modern Browsers: Chromium-based browsers (Microsoft Edge, Chrome) share the Blink rendering engine and V8 JavaScript engine, while Firefox uses Gecko. In enterprise Windows environments, Edge integrates directly with Microsoft Defender SmartScreen, Windows Security Zones, and certificate stores, and includes Developer Tools (F12) for inspecting network traffic and client-side behavior.

2. The Windows Registry

Every time you change a Windows setting, configure a service startup type, or install software, Windows stores that configuration in a centralized hierarchical database called the Windows Registry.

Registry Structure & Terminology

Hierarchy: Hive → Key → Value → Data

  • Hives (Root Keys):
    • HKEY_LOCAL_MACHINE (HKLM) – System-wide hardware, driver, service, and software settings (applies to all users).
    • HKEY_CURRENT_USER (HKCU) – Preferences and settings for the currently signed-in user.
    • HKEY_CLASSES_ROOT (HKCR) – File extension associations and COM class registrations.
    • HKEY_USERS (HKU) – Profiles for all loaded user accounts on the machine.
    • HKEY_CURRENT_CONFIG (HKCC) – Current hardware profile at boot.
  • Keys & Subkeys: Folder-like containers (e.g., HKLM\SYSTEM\CurrentControlSet\Services\Spooler).
  • Values & Data Types: Named entries inside a key holding configuration data—most commonly REG_SZ (text string), REG_DWORD (32-bit integer, e.g., Service Start = 2 for Automatic or 4 for Disabled), and REG_BINARY.

Three Ways Administrators Manage the Registry

Tool Use Case Example
Registry Editor (regedit.exe) Interactive GUI inspection, search (Ctrl+F), and manual .reg export/import backups. Right-click key → Export to C:\SpoolerBak.reg
Command Line (reg.exe) Fast queries, batch scripting, and restoring .reg backups from CMD/PowerShell. reg query HKLM\SYSTEM\CurrentControlSet\Services\Spooler
PowerShell Registry Provider Navigating HKLM: and HKCU: like filesystem drives for automation. Set-ItemProperty HKLM:\...\Spooler -Name Start -Value 4
Golden Rule of Registry Editing: Unlike normal Settings menus, regedit does not ask "Are you sure?" before saving changes. Always Export a .reg backup of the target key before editing HKLM!

3. Software Packaging & Installation Methods

Installing an application is rarely just copying files into a folder. A Windows installer typically extracts binaries to C:\Program Files, registers uninstall metadata under HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall, configures background services or drivers, and creates Start Menu shortcuts.

Format Engine / Technology Supported Platforms Pros Cons
Setup.exe Legacy Win32 executable wrapper (Inno Setup, NSIS, InstallShield) Windows 11, Windows 10, Legacy Highly customizable UI and pre-install prerequisite checks. Silent install switches vary by vendor (/S, /silent, /quiet); inconsistent uninstallers.
.msi (Windows Installer) Microsoft Windows Installer service (msiexec.exe) Windows 11, Windows 10, Windows Server Standardized silent flags (/i, /x, /quiet), transactional rollback on failure, enterprise GPO/Intune ready. Requires structured database packaging; trickier to wrap multi-step scripts without an MST/PSADT wrapper.
AppX (UWP) Universal Windows Platform container Windows 11, Windows 10 Sandboxed permissions, clean uninstall with zero registry clutter, distributed via Microsoft Store. Restricted APIs; limited to UWP architecture.
MSIX Modern Windows App Package Windows 11, Windows 10 Containerizes Win32, .NET, and UWP apps; clean installs/uninstalls, delta updates, and digital signing. Requires code-signing certificates and MSIX packaging tools for legacy apps.

Modern App Deployment & Automation

  • winget (Windows Package Manager): Built into Windows 11 for CLI discovery, silent installation, and patching (e.g., winget install Microsoft.PowerToys, winget upgrade --all).
  • msiexec.exe (Silent MSI Control): Standard administrative deployment from Command Prompt (msiexec.exe /i 7z-x64.msi /quiet to install, /x to uninstall).
  • PowerShell AppX Cmdlets: Query and remove Store/UWP packages per-user or provisioned (Get-AppPackage -Name *Sysinternals* | Remove-AppPackage).
  • Enterprise Tooling: Organizations combine Microsoft Intune / Company Portal (self-service approved catalog), Chocolatey, and PSAppDeployToolkit (PSADT) to deploy software silently across hundreds of endpoints without user interaction.

4. Windows 11 25H2 & PowerToys

  • Windows 11 Version 25H2 Servicing: Rather than a full OS wipe-and-replace upgrade, version 25H2 builds on the shared 24H2 servicing branch via a lightweight Enablement Package (eKB), turning on staged features with a single fast reboot.
  • Microsoft PowerToys: An open-source suite of administrator and power-user utilities—including FancyZones (custom window snapping), PowerRename (regex bulk file renaming), Text Extractor (OCR from any screen region), and Color Picker.
